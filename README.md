# Elektronik Makmur Jaya

Sistem informasi produk berbasis PHP yang digunakan untuk menampilkan informasi produk dan membantu memantau persediaan barang.

## Fitur

- Dashboard informasi produk
- Menampilkan total jumlah produk
- Status Stok Aman (≥ 3)
- Status Stok Kritis (1–2)
- Status Stok Habis (0)
- Perhitungan total nilai stok
- Pencarian produk
- Informasi kategori, harga, stok, dan deskripsi
- Tombol refresh data
- Informasi sistem

## Teknologi

- PHP
- XAMPP

## Cara Menjalankan

1. Clone repository ke folder `htdocs`.
2. Jalankan Apache melalui XAMPP.
3. Buka browser.
4. Akses:

`http://localhost/elektronik_makmur_jaya/`
